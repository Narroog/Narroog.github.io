# Research 发布

草稿保存在 `Writing/research/`，完成后移到 `Published/blog/research/`。

- 复制 `Writing/templates/Post Template.md` 可以创建新稿。
- 使用 `draft: false`，补全标题、摘要、日期和标签。
- 文件名使用简短英文，如 `engineering-knowledge.md`；标题可以保留中文。
- 图片放到 `Published/assets/`。
- 站内链接使用标准 Markdown，例如 `[工程学科的知识结构](engineering-knowledge.md)`。

运行 `npm run build` 和 `npm run check:routes`，确认栏目、旧网址跳转和媒体引用正常。

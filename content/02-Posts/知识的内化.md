## 引子

在Ai时代，信息量是廉价的。

但信息量的廉价不代表知识的廉价。知识本身的定义就是很模糊的，它包含的维度有很多，因此包含的信息量也很多，其中一些信息是关键的，容易让人举一反三的，而另一些信息是无效重复的。因此即使限定消耗相同信息量，对某项知识的理解程度也是不同的。在Ai时代，我们或许不需要再记忆知识了，但并不意味着不需要再学习知识了。如果每遇到一个问题就要问Ai，那思维就被框定在在Ai的知识范围内，更别说创新了。真正学习知识不是看我对某个知识掌握了多少信息量，而是需要将其内化。

我认为内化的基本原则是：内化后可以触类旁通，具有从较小的信息量扩充到较大信息量的能力；内化需要知道此知识与其他知识的联系；内化之后的知识容易让人理解。

因此我认为内化的关键属性有四个：定位、历史、结构、图像。



## 内化的四个角度

### 定位：与上下游的联系、与并列知识的联系与区别

“定位”是在回答：**这个概念位于整个知识网络的什么位置？**它包括两个方向，纵向和横向。

纵向定位：与上下游的联系。上游是它所依赖的基础、条件或输入；下游是它产生的结果、用途或影响。

横向定位：与并列知识的联系和区别。并列知识是与它处于相近层级、能够放在一起比较的概念。与并列知识进行对比，是一种准确定义的方法。



### 历史：创造的动机

这里的“历史”不是简单罗列发明年份和人物，而是在回答：**原来的方法遇到了什么问题，为什么必须创造这个新事物？**理解历史，就是了解某个知识出现的原因，这也更容易让我们理解它的功能和结构。



### 结构：内部的结构与逻辑

例如某个大知识可以被如何分类为几个部分。

理解内部的结构与逻辑，不是让我们直接理解所有相关的知识，而是当出现一个新知识时，我们可以根据这个结构，对新知识进行归类。这是一种



### 图像：内容在人理解下的映射

这里的“图像”不一定是实际照片，而是指：**把抽象概念映射成人容易理解的空间、物体或生活经验。**



## 例子

利用这四个角度，可以内化各种类型的知识，例如这里想要了解“晶体管”，就可以借助下面的表格进行理解：

| 角度 | 解释                                                         |
| ---- | ------------------------------------------------------------ |
| 定位 | 纵向：上游是半导体制造，下游是某个电路功能；横向：电阻、电容、二极管，区别在于电流电压特性 |
| 历史 | 真空管存在体积大、功耗高，难以集成，晶体管使用半导体材料，大幅缩小体积，降低功耗，因此被发明 |
| 结构 | 晶体管包含数字电路中的MOSFET、FinFET、GAAFET等，还有模拟电路中的JFET、HEMT |
| 图像 | 有栅源漏，栅极相当于“闸门”，控制电子或空穴的通行，源和漏相当于“泵”，为电子或空穴提供能量。 |



例如想要更进一步，了解晶体管下面某个具体类型，例如“FinFET”，可以借助下面的表格进行理解：

| 角度 | 解释                                                         |
| ---- | ------------------------------------------------------------ |
| 定位 | 纵向：上游是针对Fin的制造工艺，下游是某个数字电路功能；横向：MOSFET、GAAFET，区别在于制程和栅极结构 |
| 历史 | 平面晶体管变小时，栅极越来越难控制沟道，因此发明了 FinFET。  |
| 结构 | FinFET包括单fin，多fin，SOI，bulk等类型                      |
| 图像 | 相比于平面型栅极控制一个面，Fin结构使得栅极控制沟道的三个面，加强了控制能力，因此漏电减小。 |
